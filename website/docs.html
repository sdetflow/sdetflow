Documentation

Install, integrate, observe, improve.

SDETFlow is designed so another SDET can understand the architecture, install a package, run it safely, and extend it without modifying the core.

@sdetflow/playwright

npm install -D @playwright/test @sdetflow/playwright@0.2.0

Use deterministic smart locator fallback, sanitized diagnostics, bounded evidence capture, retries, seeded test data and optional AI failure analysis. AI and DOM capture are off by default.

@sdetflow/ai

npm install @sdetflow/ai@0.2.0
export OPENAI_API_KEY='...'
# or
export GEMINI_API_KEY='...'

Configure explicit task routes and model fallbacks. Use failure triage, test design, log analysis and accessibility explanations while keeping provider keys out of prompts. Cost budgets, rate controls and circuit breaking are built in.

sdetflow-api

<dependency>
  <groupId>io.github.sumantthh-sdet</groupId>
  <artifactId>sdetflow-api</artifactId>
  <version>0.2.0</version>
</dependency>

Java 17 API automation with safe retries, authentication strategies, fluent assertions, JSON-path checks and lightweight contract validation.

sdet_flow

gem install sdet_flow -v 0.2.0

Ruby API automation, redaction, retries, JSON assertions and framework adapters for Capybara/Watir-style suites.

@sdetflow/insights

npm install @sdetflow/insights@0.2.0

Normalize Playwright, JUnit, Cucumber and Allure results; calculate explainable flaky-test scores, cluster recurring failures, summarize runs and persist history through an injected storage adapter.

Security model

Credentials belong in environment variables or CI secret stores. SDETFlow redacts common secret patterns before diagnostics/AI handoff, bounds artifacts, keeps AI opt-in, treats agent tool output as untrusted data, requires host-controlled tool authorization/approval, and avoids retrying unsafe HTTP operations unless the caller explicitly establishes idempotency.
