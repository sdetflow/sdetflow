# SDETFlow v0.2.0

First public SDETFlow multi-language quality-engineering release.

## Public packages

### Playwright / TypeScript
```bash
npm install -D @sdetflow/playwright@0.2.0
```

### GenAI + Agentic AI
```bash
npm install @sdetflow/ai@0.2.0
```

Provider-agnostic OpenAI/Gemini integration, bounded agent execution, tool allowlists, approval gates, privacy controls, routing and budgets.

### Test intelligence
```bash
npm install @sdetflow/insights@0.2.0
```

Normalization and analysis for Playwright, JUnit, Cucumber and Allure results, including flake scoring, clustering and trends.

### Java API automation SDK
```xml
<dependency>
  <groupId>io.github.sumantthh-sdet</groupId>
  <artifactId>sdetflow-api</artifactId>
  <version>0.2.0</version>
</dependency>
```

### Ruby quality-engineering Gem
```bash
gem install sdet_flow -v 0.2.0
```

## Release quality gates

- Main CI green
- Chromium / Firefox / WebKit Playwright matrix
- Public npm clean-consumer install/import smoke
- Public RubyGems clean-consumer install/import smoke
- Public Maven Central clean-consumer resolve/compile/run smoke
- GPG-signed Maven Central publication
- Provider-contract coverage for OpenAI and Gemini
- Deterministic non-AI behavior remains available when AI is disabled
