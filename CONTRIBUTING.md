# Contributing to SDETFlow

Thank you for helping improve SDETFlow and its GenAI-powered quality engineering tools.

## Engineering expectations

- Add or update tests before changing public behavior.
- Do not commit credentials, proprietary employer/client code, production test data, internal selectors, or confidential architecture.
- Keep deterministic functionality independent of AI-provider availability.
- Document public API changes.
- Preserve backward compatibility within a major version.
- Prefer explicit behavior over hidden magic.

## Pull request checklist

1. Tests added/updated.
2. Release-blocking tests pass.
3. Documentation updated.
4. No secrets in diff/history.
5. Security/privacy implications reviewed.
6. Changelog entry included for user-visible behavior.
